Run Agent：面向多轮复杂任务的 Agent Harness
github.com/zhanglinrun/run-agent
2026.05 – 至今
核心技术：Python、asyncio、Agent Harness、Tool Calling、Skill、SQLite、Context Compaction、Session Resume、Tracing / Eval
项目描述：面向多轮复杂编码任务构建本地优先的 Agent Harness。按 Provider、Core、Coding、Gateway 四层统一模型、工具与会话语义；核心保留压缩与 Skill，扩展按需装配 MCP、计划、权限校验、结果验证与经验学习；以 run 命令提供交互式 CLI、多会话网关及评测入口。
  • 扩展式 Harness 架构：参考 Pi 构建 Provider、Core、Coding、Gateway 分层，通过统一扩展契约装配 MCP、计划、权限、结果验证和经验学习；宿主提供后台任务、持久状态与资源快照，结合注册回滚和版本失效管理扩展生命周期。工具执行按读写属性有界并发，8 路只读调用的中位耗时由 249.93 毫秒降至 31.18 毫秒，下降 87.52%，返回结果顺序保持一致。
  • 可干预的多会话网关：设计会话控制器与持久任务状态机，支持运行中纠正、取消及独立后台执行；结合会话内顺序执行、跨会话公平调度、前后台容量预留和工作区隔离，通过 Inbox / Outbox 完成接收去重与结果恢复投递。10,000 个调度请求全部完成，0 丢失、0 重复、0 失败、0 会话乱序；超额请求以背压拒绝而非静默丢弃。
  • 可插拔的经验学习：以 USER.md、MEMORY.md 与 Skill 管理偏好、事实和程序性经验，通过扩展事件触发受控复盘，生成带来源的候选；结合跨会话验证、版本发布和回滚，在固定模型与预算下评估迁移收益及额外成本。经验资产按字符预算（1375 / 2200）拒绝写入而非静默截断，复盘与前台运行互斥、用量归属父运行。
  • 事务化会话存储与恢复：以 SQLite 统一管理终端与网关的会话事件、分支、执行状态和资源版本，通过事务提交、写入版本校验及上下文快照重建，支持长会话恢复、历史分叉和异常状态核对，并提供一致性备份与产物恢复。单库 31 张表，写入以 expected_head 乐观并发校验，head 不匹配即拒绝而非覆盖。
  • Agent 观测与评测闭环：关联模型、工具、调度和经验版本形成执行轨迹，构建运行可靠性、任务能力和跨会话学习三类评测；通过独立环境验收、重复试验与消融对比评估质量和成本，并将真实失败案例沉淀为版本发布依据。追踪含持久化刷盘的开销为 P50 8.14 / P95 26.81 毫秒；在 HAL 同款 SWE-bench Verified Mini（50 题）以官方容器评分、每题 3 次独立采样共 150 次求解，Pass@1 74.7%、Pass@3 84.0%、Pass^3 66.0%，单次成本 $0.165，与 HAL 榜首同分而成本低 56 倍。
